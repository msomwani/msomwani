# Mayank Somwani

AI Developer building production LLM pipelines, RAG systems, and automation workflows for real clients.

## Projects

**[MeetMind](https://github.com/msomwani/Meeting_Agent)** — Fully local meeting intelligence. Chrome extension captures audio, WhisperX + pyannote handle transcription and diarization on-device, LangGraph pipeline produces summaries, action items, and decisions. No audio leaves the machine.

**[Multi-Source RAG](https://github.com/msomwani/Multi_Source_RAG)** — RAG system ingesting PDF, DOCX, TXT, images, and web sources. LangChain + Chroma for retrieval, FastAPI backend, grounded responses with no hallucination on source content.

**[Croc Ride](https://github.com/msomwani/Carpooling-system)** — Full-stack carpooling platform. Real-time geo-matching via PostGIS, WebSocket driver coordination, Kafka event lifecycle, Razorpay payments, Next.js frontend.
